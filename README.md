# AI Student–Company Matching Platform

## 🚀 Inspiration
Students often struggle to gain real-world experience, while companies find it difficult to evaluate candidates beyond resumes.  
We wanted to bridge this gap by creating a platform where skills are demonstrated through real tasks.

---

## 💡 What it does
This platform connects students and companies through a task-based system:

- Students complete real tasks assigned by companies  
- AI evaluates performance based on resume + task results  
- Companies receive ranked candidates based on ability  
- Companies can send interview invitations directly  

---

## ⚙️ How it works
1. Student uploads resume  
2. Student completes company tasks  
3. AI evaluates performance  
4. System ranks candidates  
5. Company reviews and invites top candidates  

---

## 🧠 Key Features
- AI-powered candidate evaluation  
- Task-based hiring instead of resume-only filtering  
- Real-time student–company matching  
- Interview invitation system  

---

## 🛠️ Tech Stack
- Frontend: React / Vite  
- Backend: Node.js  
- Database: PostgreSQL  
- AI: OpenAI API
